# PFD Editor · 工艺流程组态编辑器

基于 SVG 的工业流程图（PFD/P&ID）组态编辑器。采用组件化架构，支持设备组件的拖拽、连线、编辑、动画预览，以及项目保存/加载与单文件导出。

## 功能特性

- **组件化设备库**：内置多种工业设备组件（配料秤、回转窑、脱硫塔、鼓风机、阀类、搅拌器、加热炉、螺旋输送机、回转滚筒冷却机等），支持拖拽到画布、编辑、旋转、镜像。
- **管道连线**：正交路由自动布线，支持折点拖拽、线型/颜色/线宽设置、阀门标注，以及「直线连接」开关（无拐角直连端点）。
- **标签沿线拖动**：连接线上的文字标签可沿线自由拖动定位，位置随项目一起保存。
- **运行参数（Tag）**：为设备配置运行监控参数，支持搜索、增删改、排序。
- **监控器面板**：查看后端传感器实时数据（需后端接入）。
- **动画与预览**：一键运行动画（物料流动等），只读预览页自动渲染动态效果。
- **项目持久化**：本地自动保存，支持磁盘保存/加载（File System Access API，含降级方案）。
- **单文件导出**：将整个工艺流程图导出为独立单文件 HTML，便于分发到官网。
- **3D 化工流程场景**：基于 Three.js 的暗紫色调 3D 预览（另附 3D 文档）。

## 项目结构

```
├── editor.html          # 编辑器主页面（工具栏、组件面板、属性面板等）
├── editor.js            # 核心逻辑：组件渲染、连线、交互、保存/加载、动画
├── preview.html         # 只读预览页（动画粒子流动、缩放平移、设备信息面板）
├── demo.html            # 演示案例：1#还原系统（单文件可直接打开）
├── embed-demo.html      # 嵌入演示页面
├── serve.ps1            # 本地 HTTP 服务器脚本（支持 -Port 参数）
└── .trae/
    └── documents/
        └── 3d-chemical-process-flow.md   # 3D 化工流程场景设计文档
```

## 演示案例

项目内置演示案例 `demo.html`，展示「1#还原系统」工艺流程，包含锰粉仓、螺旋输送机、还原回转窑等设备。直接在浏览器中打开即可查看动态效果。

## 本地运行

该编辑器依赖 ES Module + importmap，Chrome 在 `file://` 协议下存在 CORS 限制，因此**必须通过 HTTP 服务器访问**。

### 方式一：PowerShell 脚本（推荐）

```powershell
# 在项目根目录执行，默认端口 8090
powershell -File serve.ps1

# 指定端口
powershell -File serve.ps1 -Port 8095
```

启动后浏览器访问：

- 编辑器：http://localhost:8090/editor.html
- 预览页：http://localhost:8090/preview.html

### 方式二：Python 简易服务器

```bash
# 在项目根目录执行
python -m http.server 8090
```

### 方式三：Node.js

```bash
# 在项目根目录执行
npx serve -l 8090
```

## 快速上手

1. 打开编辑器页面，从左侧组件面板拖拽设备到画布。
2. 点击设备端口进行连线，形成工艺流程。
3. 选中管道，在右侧属性面板设置标签、线型、颜色等。
4. 点击工具栏「运行」预览动画，或点击「预览」打开只读预览页。
5. 使用「保存」/「加载」持久化项目，或用「导出单文件」生成可分发版本。

## 交互操作

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 | 移动组件 / 框选 |
| 鼠标滚轮 | 缩放（以鼠标为中心） |
| 中键按住拖拽 / 空格+左键拖拽 | 平移画布 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+[ / Ctrl+] | 向左 / 向右旋转 90°（支持多选批量） |
| 标签中心 ↔ 光标 | 沿线拖动管道标签 |

> 提示：配置运行参数（Tag）时，若需对接实时数据，需后端提供 `/api/sensors/list` 与 `/api/sensors/values` 接口并开启 CORS。
