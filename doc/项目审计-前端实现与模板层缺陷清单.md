## 修复优先级建议

1. **模板层输出编码统一（治 2.1/1.2/2.2）**：共享层新增 `escapeText()`/`escapeAttr()`，颜色白名单校验 `/^#[0-9a-fA-F]{3,8}$/`；`pColorT` onchange 与导入入口双侧校验（配合 §10.5 的 schema 校验一并落地）。instrument.js:13 补 esc 是一行修复，立即做。
2. **preview.html 补 `--line3/--text4` 变量（治 7.1）**：三行修复；中期抽共享 variables.css。
3. **a11y 基线（治 3.1/3.2/3.4）**：交互 div/span 换 `<button>` 或补 tabindex/role/aria-label；模态焦点陷阱；提示色对比度提升。按 WCAG A 级做门禁。
4. **Pointer Events 替换鼠标事件（治 3.3）**：一套代码覆盖鼠标/触控/笔，顺带解决触屏不可用。
5. **嵌入协议加版本字段（治 10.1）**：`{v:1, source, type}`，接收端未知版本降级。
6. **模板纯函数化改造（治 10.2）**：与已完成文档"抽共享核心库"主线（P0 路线 1）合并执行，模板助手挂到 `TEMPLATES.<type>.helpers`，esc 显式传参。
